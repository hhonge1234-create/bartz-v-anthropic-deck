# Bartz v. Anthropic — AI 학습과 공정이용 (발표 슬라이드)

저작권분쟁사례연구 사례 발표용 HTML 슬라이드덱 (29장).

- 조작: → / 스페이스 다음, ← 이전, 화면 오른쪽 클릭 다음 · 왼쪽 클릭 이전, `#번호`로 바로 가기
- 검수용 정적 모드: `index.html?static=1`
- 애니메이션: anime.js · 데이터 그래프: matplotlib (`build/make_figs.py`) · 설명 영상: Manim (`build/scenes.py`)
- 모든 수치: `data/facts.json` (출처 쪽수 포함)
- 검증: `build/verify.py` (Playwright로 전 슬라이드 렌더·잘림·겹침·오류 검사)
